# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Astro (static output) with TypeScript, deployed to GitHub Pages from the `AxerieSoftware/axeriesoftware.github.io` repo at `axerie.com`.

## Users

People who already use, or just heard about, one Axerie tool and want to see what else exists. They arrive from a tool's site, a GitHub README or a link someone shared, and want to know quickly what each tool does and where to get it.

## Product Purpose

axerie.com is the home for Axerie, a one-person studio that builds free, open-source tools. The homepage introduces the studio in a sentence and sends visitors to each tool. Success is a visitor finding the tool they need and following its link.

## Positioning

Every tool is free, open source and made by one developer who uses them. That's the honest claim; the site never implies a team or a company.

## Capabilities and Constraints

- Two tools today, each on its own subdomain:
  - **Wingspan** (`wingspan.axerie.com`): a browser extension that adds features to the Monarch Money web app. Free and open source. Chrome and Edge (Manifest V3); Firefox and Safari experimental.
  - **.NET Config Wizard** (`dotnetconfig.axerie.com`): a browser-based wizard that generates .NET repo config (`.editorconfig`, `Directory.Build.props`, `Directory.Packages.props`, `global.json`, `nuget.config`) with analyzer presets. Runs fully client-side. Free and open source.
- Source lives under the `AxerieSoftware` GitHub organization.
- More tools will be added over time, so the tool list must grow without a redesign.
- Static only: no server, no forms, no tracking.

## Brand Commitments

- Name: Axerie (legal entity Axerie LLC). No existing logo, colors or type; the wordmark is designed with the site.
- Each tool keeps its own identity on its own site; Wingspan has its own wordmark.
- Voice matches the tools' own copy: plain and concrete, says what a tool does for you in everyday words ("See when every bill is due"), short bolded lead-ins in lists, and "Free and open source, forever." No hype, no slogans.

## Evidence on Hand

- Wingspan README and wordmark (`~/Repos/personal/wingspan/assets/`), plus screenshots in `assets/screenshots/`.
- No testimonials, user counts or press. Don't invent any.

## Product Principles

- Get visitors to the right tool in one glance.
- Say what each tool does in plain words, not marketing.
- Honest about scale: one person, free, open source.
- Adding a tool is a data change, not a design change.
